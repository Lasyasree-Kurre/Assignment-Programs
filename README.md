# Assignment Programs in C

This repository contains basic C programs created for learning and practicing fundamental programming concepts.

## Programs Included

- **BMI Calculator** – Calculates Body Mass Index.
- **Final Payable Amount** – Calculates the final amount to be paid.
- **Loan Approval** – Checks loan eligibility.
- **Login Validation** – Validates login input.
- **Positive, Negative or Zero** – Checks whether a number is positive, negative, or zero.
- **Rectangle Area and Perimeter** – Calculates the area and perimeter of a rectangle.
- **Student Grade** – Determines a student's grade based on marks.
- **Voting Eligibility** – Checks whether a person is eligible to vote.
- **Vowel Check** – Checks whether a character is a vowel.

## Learning Objectives

- Understand basic C programming concepts.
- Practice variables, data types, and operators.
- Learn conditional statements.
- Improve logical thinking and problem-solving skills.
